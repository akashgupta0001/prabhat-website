AI models for Photo Studio (control panel). These files are NOT part of the website:
Cloudflare only publishes `public/`. The browser loads them from jsDelivr's GitHub
mirror when someone uses Photo Studio, so the website stays light.

- isnet-int8.part0-2: ISNet general-use (Apache-2.0), weights quantised to int8 (47 MB)
- u2netp.onnx: U2-Net-p (Apache-2.0), fast model (4.5 MB)
